CreativeTools adds a variety of improvements to the creative editor. It is still under active development. Currently, it gives the following:

* Command pallette commands to import/export the entire map or selection
* Undo and redo for various actions
* Increased eraser selection size
* The ability to select, move around, and copy terrain
  * This can be configured in the Editing Options menu like other Creative options
* Automatic copy/pasting of wires alongside devices
* The ability to edit the channel a block is tied to
* The ability to Download and import blocks
* Command pallette command to remove everything from a map
* Find/replace for selected terrain
* Command pallette commands to create various shapes out of terrain
* Drag and drop for layers in the layer menu
* A menu to hide/show devices based on layer

The following features are also planned:

* Layer-based multiselect restriction
