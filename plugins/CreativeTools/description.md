CreativeTools adds a variety of improvements to the creative editor. It is still under active development. Currently, it gives the following:

* Command pallette commands to import/export the entire map
* Undo and redo various actions
* Increased eraser selection size
* Select, move around, and copy terrain
  * This can be configured in the Editing Options menu like other Creative options
* Copy/paste wires alongside devices
* Edit the channel a block is tied to
* Command pallette command to remove everything from a map
* Find/replace selected terrain

The following features are also planned:

* Ways to import/export parts of a map
* Layer-based multiselect restriction
* Creating shapes out of terrain
* Improving layer management somehow
