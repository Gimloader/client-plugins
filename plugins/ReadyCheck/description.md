ReadyCheck gives an in-game ready-up system that lets users of this plugin signal that they are ready for the game to start. Players are given a button to the left of the plugins button, as well as a hotkey, to toggle whether they are ready or not. Hosts are given a button at the bottom that toggles whether the game should automatically start when all players are ready or should be manually started. If the game starts automatically, a 3 second countdown will happen where anyone can cancel, then the game will start.
